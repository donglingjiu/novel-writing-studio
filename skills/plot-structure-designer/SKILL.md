# 网文剧情结构与分卷大纲设计

## 适用场景

接收人设卡与故事大纲，产出可直接交给正文写作者逐章创作的分卷大纲+章节大纲，对标起点/番茄平台追更节奏（快节奏、强钩子、章末悬念驱动读者点击下一章）。适用于超长篇连载（50万字+）的分卷节奏提前规划。

## 工作流程

### 1. 确认输入完整性

开始前确认已拿到：定稿的人设卡（主角+主要配角）、故事大纲/核心卖点。缺失时向 hub 索要，不自行编造人设。

### 2. 规划分卷结构

按整本预估字数（如无特别说明，默认按 50万字+超长连载假设）划分卷次，每卷遵循：
- 每卷有独立的小高潮/阶段性目标（不是全书唯一高潮的稀释）
- 卷与卷之间用悬念钩子衔接（卷末抛出新冲突/新身份/新危机，牵引读者进入下一卷）
- 标注每卷预估章节数区间和核心冲突升级点

### 3. 细化章节大纲

对当前需要展开的卷，逐章输出：
- **章节序号+标题**（可选，标题需体现钩子而非剧透结局）
- **本章核心事件**（一句话概括本章要发生什么）
- **爽点/钩子类型标注**：从下列类型中标注本章命中的类型（可多选）：
  - 身份反差揭示（马甲掉落/实力显露）
  - 打脸/装逼（被轻视后反杀）
  - 悬念抛出（章末留钩，制造"下一章必看"冲动）
  - 情感递进（关系突破/背叛/救援）
  - 信息差爽感（读者知道而角色不知道，或反之）
- **钩子位置**：明确标注钩子放在本章开头（吸引继续读本章）还是章末（吸引点开下一章），超长连载章末钩子是追更续订的核心手段，优先保证章末必有钩子
- **与人设/主线的挂钩**：本章如何推进人物成长弧线或主线冲突，避免注水章节

### 4. 开篇专项要求

若本次设计涉及全书前 3-5 章（开篇黄金期），额外标注：
- 主角登场后多少字内亮出核心冲突/反差点（起点/番茄同类头部作品通常在开篇 500-1000 字内建立冲突钩子）
- 首章结尾必须留强钩子，不能是平铺信息

### 5. 自检清单

交付前核对：
- 每章是否都有明确钩子位置标注，杜绝无钩子的过渡水章
- 卷末悬念是否足够牵引下一卷阅读欲望
- 节奏是否有连续多章无爽点/无冲突推进的"拖沓段"，如有需重新分布
- 人物成长弧线是否在章节节点上有对应体现，供 story_bible_keeper 后续核对

## 输出格式

```
## 分卷大纲
### 第一卷：卷名
- 核心目标：
- 预估章节：第1章 - 第N章
- 卷末钩子：

## 章节大纲（当前卷）
### 第1章：标题
- 核心事件：
- 爽点/钩子类型：
- 钩子位置：开头 / 章末
- 与主线挂钩：
...
```

## 与其他角色的协作

- 输入来自 hub 派发（人设确认通过后）；产出汇报给 hub，确认通过后转交 prose_writer 逐章写作。
- 章节大纲中涉及的新增设定/伏笔应提示 prose_writer 完成后同步给 story_bible_keeper。
